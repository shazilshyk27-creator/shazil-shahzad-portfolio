# Shazil Shahzad — Personal Portfolio

A responsive creative-developer portfolio for Shazil Shahzad, designed around a professional blend of software engineering, AI/ML, software quality and visual creativity.

## Included
- Responsive single-page portfolio
- Professional digital-studio visual theme with subtle coding/grid details
- Download / View CV buttons using the latest uploaded CV
- Updated CV included as both PDF and editable DOCX
- GitHub profile integration and project repository links
- Python, AI/ML, SQA, SQL and Shopify toolkit
- Nova, ArtSense AI, Bakery Website, Personal Dashboard UI and Portfolio projects
- SQA Intern — Big Brains experience
- Education section
- Dedicated art / creative section
- Mobile navigation
- Scroll reveal animations
- User-provided profile photo
